# munarium-api-types

The shared REST DTOs for Munarium Server: the single place JSON casing is
decided. The OpenAPI schemas derive from exactly these structs, and the
`proto` feature adds conversions from the wire types in `munarium-proto`.

Part of [Munarium](https://github.com/iokaio/munarium). Licensed under
Apache-2.0. See LICENSE and NOTICE.
