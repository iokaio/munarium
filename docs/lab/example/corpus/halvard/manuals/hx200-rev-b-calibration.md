# HX-200 bench analyser, revision B: calibration procedure

Document HM-B-CAL, applies to HX-200 revision B units (serial prefix HXB).

Revision B performs the zero offset automatically during warm-up. There is
no manual offset step in this procedure.

1. Power the unit on and allow a fifteen minute warm-up.
2. Flush the sample path twice with rinse solution R-1.
3. Load the 1.0 mL reference standard and record the reading.
4. Load the 2.0 mL reference standard and record the reading.
5. Record the calibration in the service log.

Acceptance tolerance for revision B: plus or minus 0.5 percent of the
reference value at both points.
