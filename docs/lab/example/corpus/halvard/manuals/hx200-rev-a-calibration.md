# HX-200 bench analyser, revision A: calibration procedure

Document HM-A-CAL, applies to HX-200 revision A units (serial prefix HXA).

Perform calibration after any pump or sensor replacement and at least every
ninety days.

1. Power the unit on and allow a fifteen minute warm-up.
2. Flush the sample path twice with rinse solution R-1.
3. Load the 1.0 mL reference standard and record the first reading.
4. Apply the 2.0 mL reference standard and adjust the zero offset by hand
   until the display reads within tolerance.
5. Repeat the 1.0 mL reading and confirm both readings agree.
6. Record the calibration in the service log.

Acceptance tolerance for revision A: plus or minus 1.0 percent of the
reference value at both points.
